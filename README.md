# CLTACLC

Howdy?!

Easy to use. Just copy and past the HTML code among HTML comments quotes into the area mostly after page footer.

It will show a legacy terminal style simulator with a copy-code icon using CLTACLC(Copy Long Text Area Code Legacy Control).
